This is my Mission 0 project for Hans Marketing.

The site includes:

- a navbar with desktop and mobile menu
- a hero section with a search box
- a news section with article cards
- article data loaded from a small backend
- fallback article data in case the backend is not running, because things happen
- responsive styling so it does not completely explode on smaller screens

frontend code is in `frontend/src/App.jsx` and the styling is in
`frontend/src/App.css`.

The backend is just there to provide the news articles for the page. Nothing
massive. Just enough to show the frontend can fetch and display data.

Overall this project is basically a clean-ish marketing page with a tiny API
behind it. Not perfect, but it does the job.
